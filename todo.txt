VERSION SYNC REMINDER (every release)
================================================================================

When releasing, these files MUST match:
  - package.json ? "version"
  - package-lock.json ? root version
  - src-tauri/Cargo.toml ? version
  - src-tauri/Cargo.lock ? crate version
  - src-tauri/tauri.conf.json ? "version"
  - Git tag: vX.Y.Z

GitHub Release with latest.json must exist for users to receive updates.
Source code version alone does NOT trigger updates ? only published releases do.
